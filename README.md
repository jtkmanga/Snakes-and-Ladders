# Lucky Game — Snakes & Ladders 🐍🎲

## 🎮 [เข้าเล่น Lucky Game ออนไลน์](https://snakes-and-ladders-staging.jtkmanga.workers.dev/)

**อัปเดต 13 พฤศจิกายน 2569:** เกมเปิดให้เล่นออนไลน์แล้วบน Cloudflare Worker V103 พร้อมระบบจับคู่จริง และเปิด **Public Checkout V2 สำหรับสมัคร VIP/ซื้อไอเทม** ฝั่งเซิร์ฟเวอร์แล้ว

### เล่นอย่างไร

- เปิดผ่าน Chrome หรือเบราว์เซอร์บนมือถือ ไม่ต้องติดตั้งแอป
- เข้าสู่ระบบด้วย Google และเลือกตัวละคร
- **Free Server:** เล่นฟรี จับคู่ Multiplayer ห้องละ 3 คน
- **VIP Server:** ห้องละ 2 คน สมาชิกสูงสุด 100 คน **฿100 / 30 วัน** (ราคาที่แสดงในเกม/กำหนดโดยเซิร์ฟเวอร์เป็นหลัก)
- เล่น 5 กระดานแบบสุ่ม ทอยลูกเต๋าแข่งกันถึงช่อง 100

### 💳 VIP และไอเทมเงินจริง

Public Checkout V2 เปิดใน Worker แล้ว รองรับ QR พร้อมเพย์และอัปโหลดสลิปให้ระบบตรวจด้วย Slip2Go โดย **ตรวจสอบคำสั่งซื้อ ผู้รับเงิน ยอดเงิน และสถานะจากหน้าเกมก่อนโอนทุกครั้ง** และรอจนเกมแสดงการเปิดสิทธิ์สำเร็จ

**อย่าโอนเงิน** ถ้าหน้าเกมไม่สามารถออกคำสั่งซื้อ/QR ที่ยังไม่หมดอายุได้ หรือแจ้งว่าเครื่องมือตรวจสลิปไม่พร้อม ไม่ใช้ QR เก่า ไม่โอนซ้ำเมื่อกำลังรอตรวจหรือกู้สิทธิ์ หากชำระเงินแล้วแต่ยังไม่ได้รับสิทธิ์ ให้เก็บหมายเลขคำสั่งซื้อและติดต่อผู้ดูแลเกม

### สถานะการเปิดให้บริการ

- เปิดให้เล่นผ่านลิงก์ที่ใช้ชื่อ **Staging เดิม** แต่รันโค้ดจริง V103 และไม่มีหน้าตัวอย่าง VIP/บอตของรุ่นก่อนแล้ว
- การเปิดรับชำระเงินฝั่งเซิร์ฟเวอร์ **ยังไม่ใช่หลักฐานยืนยันการซื้อเงินจริงสำเร็จครบวงจรทุกกรณี** ระบบจะตรวจความพร้อมของร้าน Slip2Go ก่อนให้สร้างคำสั่งซื้อที่ชำระได้
- ยังไม่ได้รับรองความจุพร้อมกัน 1,000–10,000 คน
