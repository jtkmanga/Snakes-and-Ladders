### ระบบ VIP และไอเทมเงินจริง (V103)

ระบบซื้อ VIP/ไอเทมสำหรับผู้เล่นทั่วไปเปิดให้ใช้งานผ่าน **QR พร้อมเพย์ในเกม** พร้อมระบบส่งสลิปให้เซิร์ฟเวอร์ตรวจสอบ Slip2Go

ราคาที่ระบุในตัวเกมล่าสุด: VIP **฿100/30 วัน**, ไอเทมเกราะกันงู **฿10**, ไอเทมรางวัลชนะ ×2 **฿20** โปรดยึด **ราคาจริงและยอดที่ยืนยันโดยเซิร์ฟเวอร์ในคำสั่งซื้อ** ก่อนทำรายการ เนื่องจากเจ้าของเกมสามารถปรับราคาได้

**คำแนะนำเพื่อความปลอดภัย**
1. จ่ายเฉพาะผ่าน QR ที่ผูกกับคำสั่งซื้อที่สร้างสำเร็จภายในหน้าเกม และตรวจสอบชื่อผู้รับกับยอดเงินก่อนโอน
2. หลังโอน ส่งสลิปผ่านหน้าเกมเพื่อยืนยัน และรอระบบแจ้งสิทธิ์ที่ได้รับ
3. หากการตรวจสลิป/การให้สิทธิ์ไม่สำเร็จ **อย่าโอนซ้ำ** ให้เก็บเลขคำสั่งซื้อแล้วติดต่อผู้ดูแล
4. อย่าส่งรหัสผ่าน Google หรือข้อมูลบัญชีธนาคารให้บุคคลที่อ้างว่าเป็นผู้ดูแล

**สถานะ:** Early Access มีการเปิดโค้ดชำระเงินจริงสำหรับผู้เล่นทั่วไปแล้ว แต่ยังไม่ได้รับรองผลทดสอบธุรกรรมจริงจากบัญชีผู้เล่นทั่วไปครบวงจร หรือรับประกันผู้เล่นพร้อมกัน 1,000–10,000 คน ผู้ดูแลอาจปิดการสร้างคำสั่งซื้อใหม่ชั่วคราวหากพบปัญหาเพื่อปกป้องรายการเดิม
