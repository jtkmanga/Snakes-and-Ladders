## 🎮 [เข้าเล่น Lucky Game](https://snakes-and-ladders-staging.jtkmanga.workers.dev/)

เกมงูและบันไดเล่นผ่านเว็บเบราว์เซอร์บนมือถือได้ ไม่ต้องติดตั้งแอป

- เข้าสู่ระบบด้วย Google
- **Free Server:** เล่น Multiplayer จับคู่สูงสุด 3 คนต่อห้อง
- มีหลายกระดาน สุ่มงูและบันได ทอยลูกเต๋าผลัดกัน และสะสมคะแนน
- รองรับการกลับเข้าเกมและติดตามอันดับผู้เล่น

**สถานะการเปิดให้บริการ:** เวอร์ชันนี้คือ **Early Access บนเซิร์ฟเวอร์ Staging ที่เปิดให้เข้าเล่นได้** ยังไม่ใช่ประกาศรับรองกำลังรองรับผู้เล่นพร้อมกัน 1,000–10,000 คน

**การซื้อ VIP และไอเทม:** ยังไม่เปิดรับชำระเงินจริงสำหรับผู้เล่นทั่วไปอย่างเป็นทางการ โปรดอย่าโอนเงินนอกระบบหรือส่งสลิปผ่านช่องทางที่ไม่ใช่หน้าเกมที่ได้รับอนุญาต

ลิงก์เข้าเล่นโดยตรง: https://snakes-and-ladders-staging.jtkmanga.workers.dev/
